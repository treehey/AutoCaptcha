## 🚀 两套登录流程

| 场景 | 自动化流程 |
| :--- | :--- |
| **统一身份认证** | 识别四位字母数字验证码 → 填写账号密码 → 提交登录。 |
| **选课系统登录** | 识别底部目标字与上方候选字 → 低置信换图 → 按顺序点击 → 填写账号密码 → 提交登录。 |
| **选课监控** | 登录后按课程关键词监控余量 → 有空位时点击“选择”并确认。 |
| **本地处理** | CNN、OCR、ONNX/WASM 推理和账号配置均在浏览器本地运行；不依赖云端打码或大模型 API。 |

两个自动登录开关在 Popup 中独立控制。选课页的手动“重新识别”只标点，不会点击或提交，便于检查当前验证码。

## 📊 识别与运行情况

### 统一身份认证图形验证码

测试口径：`round-024` 至 `round-029` 共 `180` 张用于训练和开发；`round-030` 至 `round-033` 共 `120` 张未参与训练；发布候选冻结后又采集 `round-034` 至 `round-038` 共 `150` 张全新样本，只评测一次且不调参。评测使用插件真实流程；字母大小写不敏感，数字与字母严格区分。

| 指标 | 结果 |
| :--- | :--- |
| 全新发布验证集单次成功率 | `146/150`，约 `97.3%` |
| 两批未训练样本合计 | `264/270`，约 `97.8%` |
| 相比 v4.2.0 默认流程 | `87/120` → `118/120`，净增 `31` 张 |
| 15 轮完整回归 | `444/450`，约 `98.7%`（含训练轮，泛化以全新验证集为准） |
| 平均成功尝试次数 | 约 `1.03` 次 |
| 热态 CNN 单次耗时 | 通常约 `30-45ms` |
| 含低置信 OCR 回退平均耗时 | 全新验证集约 `0.055s` |
| 2 次内成功概率 | 约 `99.93%` |
| 3 次内成功概率 | 约 `99.998%` |

### 选课系统点击验证码

选课模型使用固定背景减除、四目标/四候选匹配和本地 ONNX Runtime Web Worker。历史 `round-001..020` 的浏览器 Worker 回放为 `587/600`（`97.83%`），平均 `95.2ms`、p95 `105.7ms`；`margin >= 0.40` 的门槛用于避免低把握自动点击。该集合参与过开发或历史检查，因此它是回归指标，不是对未知验证码的成功率承诺。完整口径见 [点击验证码运行结果](docs/CLICK_CAPTCHA_RUNTIME_RESULTS.md)。

## ✨ 核心特性

| 功能 | 说明 |
| :--- | :--- |
| **🧠 双验证码识别** | 统一认证使用本地轻量 CNN + Tesseract 回退；选课系统使用本地 ONNX/WASM 点击验证码匹配模型。 |
| **🛡️ 隐私优先** | 账号配置和运行状态仅保存在 **浏览器本地 (Chrome Storage)**，不上传任何服务器。 |
| **⚡ 自动换图保护** | 选课点击验证码遇到三字、低置信或背景不匹配时自动换图重试，避免直接盲点。 |
| **🤖 双站自动登录** | 两个站点共享本地账号配置，但开关相互独立；选课页只会在检测到真实登录控件时提交。 |
| **📚 自动抢课** | 在 Popup 中输入目标课程名称，自动点击"选择"并确认弹窗；课程满员时持续监控，有空位立即抢课。 |
| **🔄 可控监控** | 可配置刷新间隔（1/2/3/5/10/30 秒），实时日志展示每轮检测结果，所有课程抢到后自动停止。 |
| **🎨 现代交互** | 极简紫韵 UI 面板，分登录助手/选课助手两个 Tab，状态开关一键配置。 |
| **🌐 选课闭环** | 选课页支持本地点击验证码自动登录，登录后无缝进入课程监控与自动抢课。 |

## 🛠️ 安装指南

本插件已发布到 Microsoft Edge Add-ons。Chrome 或需要手动安装时，请使用 GitHub Release 提供的精简安装包，无需下载整个源码仓库。

### 从 Edge 商店安装

访问 [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/hebfkinlcalfnmeeeaciaghoialpmnfp) 并点击获取。

### 从 GitHub 发布版安装（Chrome / 开发者模式）

1.  **下载发布包**：打开 [GitHub Releases](https://github.com/treehey/AutoCaptcha/releases/latest)，在 `Assets` 中下载 `NJU-Login-Pro-v*.zip`。不要下载 `Source code`，它是完整仓库源码，不能作为安装包使用。

2.  **解压发布包**：将下载的 ZIP 解压到一个固定文件夹；解压后的文件夹根目录应直接包含 `manifest.json`。

3.  **打开 Chrome 扩展程序页面**：
    * 在 Chrome 浏览器中，访问 `chrome://extensions`。
    * 或点击浏览器右上角的三个点 -> `更多工具` -> `扩展程序`。

4.  **启用开发者模式**：
    * 在扩展程序页面的右上角，打开 `开发者模式` 开关。

5.  **加载已解压的扩展程序**：
    * 点击左上角的 `加载已解压的扩展程序` 按钮。
    * 选择刚才解压的发布包文件夹。

6.  **固定插件**：
    * 安装成功后，插件会出现在浏览器工具栏的拼图图标中。点击拼图图标，然后点击 `NJU Login Pro` 旁边的**图钉**图标，将其固定在工具栏上，方便快速访问。

## 💡 使用方法

### 首次配置

1.  **配置账号信息**：
    * 点击浏览器工具栏上的插件图标，切换到「**🔐 登录助手**」Tab。
    * 输入学号/工号和密码并点击“保存”。账号和验证码均只在浏览器本地处理。

2.  **选择自动化范围**：
    * 「统一认证自动登录」：访问认证页后自动识别图形验证码、填写账号密码并提交。
    * 「选课系统自动登录」：访问选课登录页后自动识别点击验证码；置信度不足时自动换图重试，通过门槛后按顺序点击、填写账号密码并提交登录。
    * 两个开关独立控制，默认开启；任一功能都可单独暂停。

### 选课助手（自动抢课）

1.  在浏览器中打开选课系统；如尚未登录，可先在登录页启用点击验证码自动登录。
2.  点击插件图标，切换到「**📚 选课助手**」Tab。
3.  在文本框中输入目标课程名称（每行一个，支持模糊匹配），例如：
    ```
    仙林游泳初级
    仙林足球初级
    ```
4.  选择刷新间隔（建议 5 秒以上，避免过于频繁）。
5.  点击「**▶ 开始监控**」：
    * 如果课程有余量，插件自动点击「选择」按钮并确认弹窗，立即完成选课。
    * 如果课程已满，持续监控，一旦有空位立即尝试抢课。
    * 所有目标课程抢到后自动停止，日志区实时显示每轮检测结果。
6.  点击「**⏹ 停止监控**」可随时手动停止。

## 🌐 支持的网站

### 1. **选课系统 · 自动登录与自动抢课**
   - 网址：`https://xk.nju.edu.cn/`
   - 登录：✅ 本地识别四字点击验证码 + ✅ 低置信自动换图 + ✅ 自动点击、填充并提交
   - 登录后：✅ 模糊匹配课程名 + ✅ 自动点击“选择”按钮 + ✅ 自动确认弹窗 + ✅ 满课持续监控

   - 刷新间隔：可选 1 / 2 / 3 / 5 / 10 / 30 秒（最小 1 秒）
   - 支持同时监控多门课程，全部抢到后自动停止

   - 网址：`https://authserver.nju.edu.cn/`
   - 验证码：图形验证码（4位字母数字）
   - 功能：✅ 自动识别、自动填充、自动登录
   - 当前全新发布验证集：`146/150`，约 `97.3%`；平均约 `1.03` 次可识别成功

## ⚙️ 技术栈

* **HTML/CSS/JavaScript**：构建插件界面和核心逻辑。
* **Chrome Extension API**：`chrome.storage` 本地数据存储；`chrome.tabs` + `chrome.runtime.sendMessage` 实现 Popup 与页面脚本的实时通信。
* **本地轻量 CNN**：直接从原始彩色字符槽识别统一认证验证码，权重随扩展打包，由纯 JavaScript 在浏览器本地推理。
* **Tesseract.js**：作为首位 `c/e` 保护、极低置信字符和模型异常时的本地回退。
* **ONNX Runtime Web WASM**：运行选课点击验证码的本地匹配模型和固定背景预处理，不加载远程模型或脚本。

## ⚠️ 注意事项

* 本插件仅为学习交流和个人便利而开发，请勿用于非法用途。
* 数据仅在您的浏览器本地存储，不会上传到任何服务器。但请注意，在公共电脑上使用自动填充功能仍存在安全风险。
* 两个登录页面的结构或验证码样式发生变化时都可能需要适配更新。
* 选课系统只有达到固定置信门槛、检测到当前登录控件且账号已配置时才会自动点击并提交；任何一项不满足时会保留人工处理。
* 极端模糊或页面版本变化时仍可能需要手动完成验证码或登录。
