## 🚀 亮点与实测

| 亮点 | 说明 |
| :--- | :--- |
| **无需大模型 API** | 不依赖 GPT、Claude 或第三方识别接口；无需 API Key，也不会产生模型调用费用。 |
| **本地 OCR 检测** | 内置 Tesseract.js 与本地图像预处理，统一身份认证验证码图片不上传服务器。 |
| **增强验证码优化** | 针对彩色字符、横线/斜线干扰、大小写混淆加入多路预处理和候选投票。 |
| **更快自动登录** | OCR worker 预热后，验证码识别通常在亚秒级完成，识别后自动填充并提交。 |

### 当前验证码实测

测试口径：`7` 轮共 `210` 张增强版统一身份认证图形验证码样本，使用当前 `content.js` 在浏览器环境中运行；字母大小写不敏感，数字与字母严格区分。耗时仅统计验证码 OCR 阶段，不含页面加载、账号密码提交和网络响应。

| 指标 | 结果 |
| :--- | :--- |
| 混合回归单次识别成功率 | `175/210`，约 `83.3%` |
| 常规增强样本成功率 | 可达 `25+/30` |
| 平均成功尝试次数 | 约 `1.20` 次 |
| 单次 OCR 平均耗时 | 约 `0.24s` |
| 验证码阶段期望耗时 | 约 `0.29s` |
| 2 次内成功概率 | 约 `97.2%` |
| 3 次内成功概率 | 约 `99.5%` |

## ✨ 核心特性

| 功能 | 说明 |
| :--- | :--- |
| **🧠 智能识别** | 内置 **Tesseract.js** 引擎，本地识别图形验证码，无需联网、无需大模型 API。 |
| **🛡️ 隐私优先** | 数据仅加密存储于 **浏览器本地 (Chrome Storage)**，绝不上传任何服务器。 |
| **⚡ 快速响应** | 页面加载后自动启动 OCR，识别完成即填充并提交，失败时自动刷新重试。 |
| **🤖 智能填充** | 自动判断浏览器填充状态。支持「强制填充」模式，解决账号冲突。 |
| **📚 自动抢课** | 在 Popup 中输入目标课程名称，自动点击"选择"并确认弹窗；课程满员时持续监控，有空位立即抢课。 |
| **🔄 低频监控** | 可配置刷新间隔（3/5/10/15/30 秒），实时日志展示每轮检测结果，所有课程抢到后自动停止。 |
| **🎨 现代交互** | 极简紫韵 UI 面板，分登录助手/选课助手两个 Tab，状态开关一键配置。 |
| **🌐 多网站支持** | 统一身份认证自动登录，选课系统登录后提供课程监控与自动抢课。 |

## 🛠️ 安装指南

本插件已发布到 Microsoft Edge Add-ons，也可以以“开发者模式”从源码安装。

### 从 Edge 商店安装

访问 [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/hebfkinlcalfnmeeeaciaghoialpmnfp) 并点击获取。

### 从源码安装

1.  **下载仓库**：将本 GitHub 仓库克隆或下载到本地：
    ```bash
    git clone [https://github.com/你的用户名/你的仓库名.git](https://github.com/你的用户名/你的仓库名.git)
    ```
    或直接点击 `Code` -> `Download ZIP` 下载。

2.  **解压文件**：如果下载的是 ZIP 文件，请将其解压到一个你容易找到的文件夹。

3.  **打开 Chrome 扩展程序页面**：
    * 在 Chrome 浏览器中，访问 `chrome://extensions`。
    * 或点击浏览器右上角的三个点 -> `更多工具` -> `扩展程序`。

4.  **启用开发者模式**：
    * 在扩展程序页面的右上角，打开 `开发者模式` 开关。

5.  **加载已解压的扩展程序**：
    * 点击左上角的 `加载已解压的扩展程序` 按钮。
    * 选择你之前解压的插件文件夹 (`NJU-Login-Pro-main` 或你克隆的仓库文件夹)。

6.  **固定插件**：
    * 安装成功后，插件会出现在浏览器工具栏的拼图图标中。点击拼图图标，然后点击 `NJU Login Pro` 旁边的**图钉**图标，将其固定在工具栏上，方便快速访问。

## 💡 使用方法

### 自动登录

1.  **配置账号信息**：
    * 点击浏览器工具栏上的插件图标，切换到「**🔐 登录助手**」Tab。
    * 输入学号/工号和密码，按需开启各开关，点击"保存"。

2.  **自动登录**：
    * 访问南大统一身份认证登录页面，插件自动识别验证码并填充登录。
    * **统一身份认证**：自动识别图形验证码 → 自动填充 → 自动点击登录
    * **选课系统**：当前不支持点击式验证码自动识别或自动登录；请先手动登录，再使用选课助手

### 选课助手（自动抢课）

1.  在浏览器中打开选课系统并登录，进入**体育课**或目标选课页面。
2.  点击插件图标，切换到「**📚 选课助手**」Tab。
3.  在文本框中输入目标课程名称（每行一个，支持模糊匹配），例如：
    ```
    仙林游泳初级
    仙林足球初级
    ```
4.  选择刷新间隔（建议 5 秒以上，避免过于频繁）。
5.  点击「**▶ 开始监控**」：
    * 如果课程有余量，插件自动点击「选择」按钮并确认弹窗，立即完成选课。
    * 如果课程已满，持续监控，一旦有空位立即尝试抢课。
    * 所有目标课程抢到后自动停止，日志区实时显示每轮检测结果。
6.  点击「**⏹ 停止监控**」可随时手动停止。

## 🌐 支持的网站

### 1. **统一身份认证系统** 
   - 网址：`https://authserver.nju.edu.cn/`
   - 验证码：图形验证码（4位字母数字）
   - 功能：✅ 自动识别、自动填充、自动登录
   - 当前混合回归样本：`175/210`，约 `83.3%`；平均约 `1.20` 次可识别成功

### 2. **选课系统 · 自动抢课** (v3.1 新增)
   - 网址：`https://xk.nju.edu.cn/`
   - 登录说明：需先手动完成选课系统登录；当前不支持点击式验证码自动识别或自动登录
   - 入口：插件 Popup → 「📚 选课助手」Tab
   - 功能：✅ 模糊匹配课程名 + ✅ 自动点击"选择"按钮 + ✅ 自动确认弹窗 + ✅ 满课持续监控
   - 选择按钮：`.cv-choice`；确认按钮：`.cv-sure.cvBtnFlag`
   - 刷新间隔：可选 1 / 2 / 3 / 5 / 10 / 15 / 30 秒（最小 1 秒）
   - 支持同时监控多门课程，全部抢到后自动停止

## ⚙️ 技术栈

* **HTML/CSS/JavaScript**：构建插件界面和核心逻辑。
* **Chrome Extension API**：`chrome.storage` 本地数据存储；`chrome.tabs` + `chrome.runtime.sendMessage` 实现 Popup 与页面脚本的实时通信。
* **Tesseract.js**：浏览器端 OCR 识别库，用于处理统一身份认证图形验证码；无需云端模型或大模型 API。

## ⚠️ 注意事项

* 本插件仅为学习交流和个人便利而开发，请勿用于非法用途。
* 数据仅在您的浏览器本地存储，不会上传到任何服务器。但请注意，在公共电脑上使用自动填充功能仍存在安全风险。
* 若南京大学统一身份认证页面结构发生变化，插件可能需要更新以适配新的元素选择器。
* 选课系统点击式验证码需要手动完成，插件仅在登录后的选课页面执行课程监控和自动抢课。
* Tesseract.js 识别率受验证码复杂度和清晰度影响，极端情况下可能需要手动输入。
