# NJU Login Pro v6.2.0

v6.2.0 重点重构课程监控模块，目标是先保证选课结果判定正确，再提高跨页面监控、失败恢复和日常使用体验。

## 主要变化

- 选课提交后必须通过精确教学班状态或服务端最终结果二次验证，不再把点击确认视为成功。
- 同名课程会收集全部候选教学班；首个教学班失败或冲突后继续尝试其他候选。
- 使用课程和教学班 ID 保存精确目标，并支持从课程页加入监控、从收藏页导入以及教师、时间、校区过滤。
- 新增 CourseGroup、要求数量、优先级和保底策略；默认不会自动退掉已经选中的保底课程。
- 课程查询优先复用页面原生查询格式，缺少可靠模板时回退 DOM；查询和提交保持有界调度并对临时错误退避。
- 页面刷新、内容脚本重载或登录失效时保存会话检查点；重新登录并进入当前选课轮次后先验证，再恢复监控。
- 新增课程页雷达、明确的待启动/监控/验证/失败状态、页面目标添加与移除操作，以及重新设计的 Popup 选课配置界面。
- README 增加产品界面预览、浏览器和站点支持矩阵、权限说明、自动恢复边界及更准确的安装入口。

## 升级提示

- 旧版课程名称会迁移为关键词目标；建议在选课页重新使用“加入监控”保存精确教学班。
- 浏览器重启后不会自行恢复真实选课提交，需要用户重新点击“开始监控”。
- 自动恢复存在超时和连续失败限制；无法确认页面状态时会转为人工处理。
- 手动安装用户应下载 `NJU-Login-Pro-v6.2.0.zip`，不要下载 GitHub 自动生成的 `Source code`。

## 验证范围

- 全部离线验证覆盖状态机、多教学班、提交失败、未知提交保护、课程组、查询路由、登录恢复和会话恢复。
- 已在真实选课页验证运行任务进入轮次预备页后自动返回课程页并继续监控。
- 网站站内“退出”不会立即使当前选课会话失效，因此自然会话过期后的完整链路主要由自动化回归覆盖；页面结构变化时仍可能需要人工登录。
