# NJU Login Pro v6.3.3

这是一个多轮次选课登录与任务恢复修复版本。

## 修复内容

- 登录成功后出现“选择轮次”弹窗时，插件会立即结束登录阶段，不再停留在“等待页面响应”。
- 轮次页仍残留旧验证码节点时，不再继续识别、标记或点击验证码；页面切换期间尚未返回的识别结果也会被丢弃。
- 课程监控因登录失效而恢复时，会记住任务原来的选课轮次，并在重新登录后自动选择同一轮次。
- 如果原轮次已经不存在或不可选，插件会停止自动选择并提示人工处理，不会擅自选择第一项。
- 真正重新回到登录页时，验证码识别会恢复，后续自动登录不受影响。

## 安装

- 从 GitHub Release 下载 `NJU-Login-Pro-v6.3.3.zip`。
- 解压后在浏览器扩展管理页加载该文件夹，或将压缩包提交到扩展商店。
- 不要下载 GitHub 自动生成的 `Source code` 压缩包。

本版本不会修改已有课程监控目标；自动恢复只会选择任务原先所属的精确轮次。
