# NJU Login Pro v6.3.0

v6.3.0 重点改进课程监控的跨页面能力、公共课稳定性和页面交互。已有登录设置与课程目标会继续保留，无需重新配置。

## 主要变化

- 监控目标在其他课程分类时，会在运行中自动切换到对应页面继续检查，不再把“当前页没有这门课”误显示成目标不存在。
- 公共课查询每连续完成 3 次后至少冷却 1 秒，降低多目标瞬时请求触发限流或退出登录的概率；收藏页维持原有速度。
- 收藏页、公选课页和其他课程页加入的精确教学班会统一类别，旧目标可在重新导入收藏时补齐分类。
- 课程雷达增加立即检查、间隔预设、目标跳转与移除、收藏导入、隐藏已选目标、复制脱敏诊断，以及位置和尺寸重置。
- 雷达可拖动、调整大小或收成胶囊；标题栏“×”只隐藏面板，“关闭选课页增强”才会同时关闭行内按钮和布局增强。
- Popup 的运行日志现在只会出现在“课程监控”页，不再混入“登录助手”页。
- 登录失效仍会先保存任务，在同一标签页完成登录并进入当前轮次后验证恢复；连续失败会转为人工处理。

## 使用提示

- “立即检查”只在监控运行且空闲时可用，不会跳过退避、登录恢复或公共课查询节流。
- 运行中移除目标会先要求“停止并移除”，防止仍在执行的旧任务覆盖配置。
- 课程监控仍需要保持选课标签页打开；窗口可以不在前台，但浏览器可能对后台标签页计时器进行节流。
- 手动安装用户应下载 `NJU-Login-Pro-v6.3.0.zip`，不要下载 GitHub 自动生成的 `Source code`。

## 验证范围

- 186 项离线测试全部通过。
- 新增覆盖跨分类自动导航、公共课三次查询冷却、立即检查安全门槛、目标移除、浮动菜单、胶囊键盘入口和减少动态效果。
- 正式发布包继续使用白名单构建，没有新增浏览器权限。
