# NJU Login Pro v6.0.0

## 统一身份认证滑块

- 适配统一身份认证当前使用的拼图滑块安全验证。
- 在浏览器本地解析挑战图片、定位拼图缺口并构造验证轨迹，不使用云端打码、远程模型或第三方签名服务。
- 验证通过后复用页面现有的 AES 密码格式与原生表单提交，继续遵循认证站点的正常登录流程。
- 登录成功后立即停止自动登录任务；短时间重新进入登录页时可以正常发起新一轮登录。
- 保留旧版四位图形验证码的本地 CNN/Tesseract 兼容路径。

匿名在线挑战最终校准为 `15/15` 通过，平均约 `1.86s`、p95 约 `1.97s`。登录页取消固定的 `800ms` 启动等待后，正常首次提交预计比初版滑块实现快约 `0.98s`。

## 选课系统

- 本地识别中文点击验证码，置信度不足、三字验证码或背景不匹配时自动换图。
- 达到安全门槛后按顺序点击验证码、填写已保存的账号密码并提交登录。
- 登录完成后自动清除验证码标点层，随后可继续使用课程余量监控与自动选课。
- 统一认证与选课系统自动登录开关相互独立。

## 隐私与安装

- 验证码图片、账号配置和模型推理均留在浏览器本地，不需要大模型 API 或 API Key。
- 下载 `NJU-Login-Pro-v6.0.0.zip`，解压后在 Edge 或 Chrome 的扩展管理页开启开发者模式，再选择“加载已解压的扩展程序”。
- Edge Add-ons 商店版本需要等待商店审核；审核通过前可使用本 Release 的 ZIP 安装。
