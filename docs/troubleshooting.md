# 常见问题与排查

排查时不要在公开 Issue 中粘贴账号、密码、Cookie、包含个人信息的页面源码或未脱敏截图。

## 安装包无法加载

确认以下事项：

- 已下载 Release 资产中的 `NJU-Login-Pro-v*.zip`，而不是 `Source code`；
- ZIP 已完整解压；
- 选择的目录根部直接包含 `manifest.json`；
- 没有选择 ZIP 文件本身或多套一层的父目录。

如果浏览器显示具体文件和行号，请记录错误文字，但先移除其中可能出现的本地用户名路径。

## 安装后没有反应

1. 刷新安装扩展之前已经打开的南大页面。
2. 打开扩展，确认账号配置完整且对应自动登录开关已开启。
3. 确认地址确实属于 `authserver.nju.edu.cn` 或 `xk.nju.edu.cn`。
4. 在扩展管理页确认扩展已启用且没有运行时错误。
5. 页面若刚更新过，先人工登录；不要反复触发自动提交。

## 统一认证停在滑块页面

这通常表示定位、服务端验证或页面结构不满足自动处理条件。请人工拖动官方滑块完成登录。若问题持续出现，可提交脱敏后的浏览器版本、扩展版本、发生时间和错误文字。

不要只报告“识别失败”：请说明是没有加载、定位后验证失败、填写后未提交，还是登录后又回到登录页。

## 提前准备统一认证没有生效

该功能默认关闭，且只有在下列条件全部满足时运行：

- 已保存账号和密码；
- “统一认证自动登录”和自动提交处于开启状态；
- 本次浏览器会话尚未尝试；
- 用户没有同时打开统一认证页或主动退出。

它每个浏览器会话最多尝试一次，不是保活服务。失败后如需重试，请直接打开认证页人工处理；不要依赖重复开关来绕过保护。

## 选课验证码不断换图

三目标验证码、背景变化、页面尺寸不匹配或置信度不足都会触发换图。这是避免错误点击的保护行为。持续失败时请关闭选课自动登录并人工完成验证码。

## 课程监控没有找到目标

- 确认当前已经登录并位于课程列表页面；
- 每行只填写一个课程关键词；
- 使用足以区分课程的名称片段；
- 检查课程是否在当前批次、校区或分类中可见；
- 查看日志中是否出现“未找到”“满员”或页面通信错误。

建议使用 5 秒或更长刷新间隔。频率过高不会提高页面本身的数据更新速度，还可能增加系统负担。

## 手动安装版本如何更新

1. 下载新的 Release 发布包；
2. 退出或暂停正在运行的课程监控；
3. 解压并替换旧发布目录；
4. 在扩展管理页选择“重新加载”；
5. 打开面板确认显示的新版本号。

如果跨多个大版本升级后行为异常，可卸载旧扩展并重新安装。卸载会清除本地配置，请先确认自己记得账号信息。

## 如何提交有效问题

请使用仓库的 Bug 模板，并提供：

- 扩展版本；
- 浏览器名称和版本；
- 发生问题的网站及页面阶段；
- 可重复的操作步骤；
- 期望行为和实际行为；
- 已脱敏的错误文字或截图。

安全问题使用[私下报告流程](../SECURITY.md)，不要创建公开 Issue。
