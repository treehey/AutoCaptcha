# NJU Login Pro v6.5.0

这是一个课程监控速度、公共课稳定性和专业课提交可靠性更新。

## 更灵活的监控速度

- Popup 可以直接填写以秒为单位的自定义监控间隔，最低为 `0.1` 秒。
- 课程雷达新增 1 秒和 2 秒快捷选项，并会准确显示当前自定义间隔。
- 收藏、专业等课程继续按用户设置的速度检查，不会因为任务里同时存在公共课而全部变慢。

## 公共课查询更稳

- 公共课查询单独采用“每批最多 3 门、批次间至少 1 秒”的安全节奏，避免短时间请求过多导致限流或退出登录。
- 推荐先把公共课加入学校收藏，再从收藏页加入监控；收藏查询通道不需要公共课页面的额外批次冷却。
- 公共课提交明确触发限流时会直接重新登录并恢复任务，不再等待一次无意义的普通退避。

## 修复有空位却不选课

- 修复接口已发现精确教学班有余量，但专业课教学班卡片或“选择”按钮稍后才渲染时，插件反复刷新却没有提交的问题。
- 当前轮会等待对应教学班 ID 的按钮就绪，找到后立即继续选课；普通无余量扫描不会因此增加等待。
- 仍然严格使用教学班 ID 匹配，不会为了追求速度而点击同名的其他教学班。

## 安装

- 手动安装用户请下载本 Release 下的 `NJU-Login-Pro-v6.5.0.zip`，不要下载 GitHub 自动生成的 `Source code`。
- 解压后在浏览器扩展管理页加载该文件夹；Edge 商店用户可等待商店审核后的自动更新。

本版本不会修改已有课程监控目标，不新增浏览器权限，也不会把账号、课程查询内容或登录信息发送到项目自建服务器。
