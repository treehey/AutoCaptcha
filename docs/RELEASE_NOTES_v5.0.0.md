# NJU Login Pro v5.0.0

## Local lightweight CNN captcha recognition

- Adds raw-color character-slot CNN recognition with automatic Tesseract OCR fallback for low-confidence results.
- Adds login-page feedback for recognition, filling, automatic login, retries, and failures.
- Captcha recognition, model inference, and credential processing stay in the browser. No large-model API or cloud service is required.

## Install from GitHub

Download `NJU-Login-Pro-v5.0.0.zip` from the release assets below. Do not download `Source code`, which is the complete repository rather than the extension package.

1. Extract the ZIP archive.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Choose Load unpacked and select the extracted folder that directly contains `manifest.json`.
