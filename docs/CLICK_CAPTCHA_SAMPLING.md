# 选课点击验证码采样

此工具用于收集选课系统点击式中文验证码的原图和手动点击坐标，为后续本地字形匹配模型提供训练与验证数据。采样不会自动点击、不会读取账号密码，也不会把图片上传到任何服务。

## 采样

1. 在浏览器中加载当前开发版扩展，连接学校 VPN 后打开选课系统。
2. 打开扩展 Popup，进入“选课”页，找到“点击验证码采样”。
3. 点击“开始采样”。页面会用紫色虚线框标出当前识别到的验证码图片。
4. 采样器会先判断目标数。遇到三字验证码时自动触发 `.verify-refresh`，直到出现四字验证码；连续五次仍未得到四字验证码时停止并提示人工处理。
5. 在紫色框内按下方提示正常手动完成四次点击。扩展会在最后一次点击后立即保存一条原图与坐标样本。
6. 扩展会先等待页面是否自行换图；未换图时会优先触发选课页的 `.verify-refresh` 刷新控件，最后才对验证码图片请求一张新图。对于 Canvas 验证码，会等待重绘稳定后再继续采样，无需重新打开 Popup。
7. 自动刷新失败时，采样会停止并在 Popup 中说明原因；此时可手动刷新后再点击“开始采样”。
8. 验证码失败时，在 Popup 中点击“删除最近”，移除刚刚保存的错误样本。
9. 每轮采集完成后点击“导出”，浏览器会保存一个 `nju-click-captcha-samples-*.json` 文件。导出数据会记录本轮自动跳过的三字验证码数量。

采样默认关闭，刷新选课页后也会自动关闭。单次最多在浏览器本地暂存 30 条样本；请在达到上限前导出。

可用冻结样本回放三/四字检测器：

```powershell
python scripts/verify-click-captcha-target-count.py
```

## 导入仓库

将导出的 JSON 文件放在任意本地位置，然后执行：

```powershell
node scripts/import-click-captcha-samples.mjs <导出文件路径> --round 001
```

导入结果位于 `data/click-captcha-samples/round-001/`：

```text
round-001/
  images/
    0001.png
  metadata.json
  source-export.json
```

导入脚本会验证每条样本都包含原图和与目标数一致的坐标，并拒绝覆盖已经存在的轮次目录。导出的原始 JSON 会作为 `source-export.json` 一并保留。导入后应立即检查样本数量、查看图像与坐标，再将该轮次提交到 Git。

## 数据约定

`metadata.json` 的点击坐标同时包含像素坐标和 `0–1` 的相对坐标。新采样只接受四字验证码；历史三字样本及其修正记录继续保留，用于目标数检测回归，不作为插件自动识别门槛。后续切分、匹配和模型评测应优先使用相对坐标，避免不同浏览器缩放比例导致标注失效。历史样本若曾被旧采样器强制记录第四次点击，其原始记录与训练用选择会保存在 `data/click-captcha-samples/corrections.json`，不会覆盖原始数据。
