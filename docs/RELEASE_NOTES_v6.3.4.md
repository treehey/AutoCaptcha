# NJU Login Pro v6.3.4

这是一个选课根地址登录兼容性修复版本。

## 修复内容

- 从 `https://xk.nju.edu.cn/` 登录后直接出现“选择轮次”弹窗时，插件现在会正确结束登录阶段并解除遮罩。
- 根地址轮次页仍残留旧验证码节点时，不再继续识别、标记或点击验证码。
- 监控任务登录失效后从根地址恢复时，仍会精确选择任务原来的轮次，并且只提交一次。
- 页面识别仅允许根路径 `/` 与官方 `index.do` 入口；其他路径即使出现同名 DOM，也不会触发自动选轮次。

## 安装

- 从 GitHub Release 下载 `NJU-Login-Pro-v6.3.4.zip`。
- 解压后在浏览器扩展管理页加载该文件夹，或将压缩包提交到扩展商店。
- 不要下载 GitHub 自动生成的 `Source code` 压缩包。

本版本延续 v6.3.3 的原轮次恢复策略，不会修改已有课程监控目标。
