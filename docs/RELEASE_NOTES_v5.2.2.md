# NJU Login Pro v5.2.2

## Popup 体验优化

- 将低频“验证码测试 / 重新识别”移至面板底部的折叠区域，打开扩展时优先显示账号配置与自动登录控制。
- 修复首次使用时空账号表单将禁用按钮显示为“已保存”的问题；现在会明确提示“请填写账号”或“请填写完整账号”。
- 统一认证页和选课页的手动验证码测试功能保持不变；选课页手动识别仍只标出顺序，不会自动点击或提交。

## 下载与安装

下载 `NJU-Login-Pro-v5.2.2.zip`，解压后在 Edge 或 Chrome 的扩展管理页开启开发者模式，并选择“加载已解压的扩展程序”。请选择直接包含 `manifest.json` 的解压目录。
