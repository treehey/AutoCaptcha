# NJU Login Pro v5.2.1

## 选课系统自动登录

- 新增完整的选课登录链路：本地识别点击验证码，达到置信门槛后按顺序点击、填写已保存账号密码并提交登录。
- 选课自动登录与统一身份认证自动登录独立控制，均可在 Popup 中单独暂停。
- 低置信或三字验证码会自动换图重试；未检测到选课登录控件、账号密码未配置或页面版本不匹配时，不会盲目点击或提交。
- 修复登录完成后标点覆盖层残留在用户信息页的问题。

## 发布包

下载 `NJU-Login-Pro-v5.2.1.zip`，解压后在 Edge 或 Chrome 的扩展管理页开启开发者模式，并选择“加载已解压的扩展程序”。请选择直接包含 `manifest.json` 的解压目录。

验证码识别、模型推理和账号处理全部在浏览器本地完成；扩展不需要大模型 API、云端打码服务或 API Key。
