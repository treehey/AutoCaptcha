# NJU Login Pro v6.2.1

v6.2.1 是一次选课登录安全性与易用性补丁：自动登录开始时更及时地防止误操作，同时确保异常情况下用户始终可以接管。

## 主要变化

- 进入选课系统登录页后，扩展会立即遮住官方登录面板，避免手动点击干扰正在进行的验证码识别和登录提交。
- 遮罩的准备、识别、提交和错误状态都有时间上限；关闭自动登录、进入人工处理或页面未按预期跳转时会自动解除。
- 登录请求提交后只显示“等待页面响应”，不会在网站确认前宣称登录成功。
- Popup 中的“提前准备统一认证”改名为更通俗的“无感登录”，相关状态、帮助文字和用户文档一并更新。
- 原有开关和本地保存的设置无需迁移，升级后会继续生效。

## 升级提示

- 手动安装用户应下载 `NJU-Login-Pro-v6.2.1.zip`，不要下载 GitHub 自动生成的 `Source code`。
- 如果自动登录未完成，遮罩会自动消失，此时可以直接在学校页面人工登录。
- “无感登录”仍默认关闭；它需要先开启统一认证的“访问时自动登录”。

## 验证范围

- 152 项离线测试全部通过。
- 新增测试覆盖登录面板立即拦截、设置关闭后释放、提交未跳转时超时释放，以及新状态替换旧状态时的竞态。
- 正式发布包经过白名单构建检查，未新增浏览器权限。
