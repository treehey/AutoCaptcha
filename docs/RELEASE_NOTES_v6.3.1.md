# NJU Login Pro v6.3.1

v6.3.1 主要加强选课监控的请求隔离、结果归因和异常保护，同时减少 Popup 帮助信息请求携带的数据。

## 主要变化

- Popup 帮助元数据现在只发送纯文本内容，不发送页面、账号或其他上下文数据。
- 自动选择和确认只会把当前教学班关联到对应的加密 volunteer 请求，并与其他手动请求隔离，降低误关联风险。
- 直拒和状态结果按候选教学班精确归因，同名但不同 ID 的候选不会互相污染状态。
- 未知扫描错误采用 5、10、20、40、60 秒的有界退避，避免异常期间持续高频请求。
- 相同结构异常连续 5 次后自动暂停监控；暂停状态会保存，Popup 和课程雷达会明确显示暂停及处理提示。

## 权限说明

- WAR 的 `<all_urls>` 权限本版本仍未收窄，不应将权限收窄描述为本次更新内容。
- 本版本没有新增浏览器权限。

- 手动安装请下载 `NJU-Login-Pro-v6.3.1.zip`，不要下载 GitHub 自动生成的 `Source code`。
