# 用户使用指南

本指南面向从商店或 GitHub Release 安装 NJU Login Pro 的普通用户。扩展支持 Chromium 内核的 Microsoft Edge 和 Google Chrome。

## 安装

### Microsoft Edge

打开 [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/hebfkinlcalfnmeeeaciaghoialpmnfp)，选择“获取”。

### Google Chrome

1. 从 [GitHub Releases](https://github.com/treehey/AutoCaptcha/releases/latest) 下载文件名类似 `NJU-Login-Pro-v*.zip` 的发布包。
2. 解压 ZIP。不要直接加载 ZIP，也不要下载 `Source code`。
3. 打开 `chrome://extensions`，开启“开发者模式”。
4. 选择“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
5. 将扩展固定到浏览器工具栏。

手动安装版本不会像商店版本一样自动更新。下载新发布包后，应覆盖或替换原目录，再到扩展管理页选择“重新加载”。

## 首次配置

1. 打开扩展，进入“登录助手”。
2. 填写学号或工号和统一身份认证密码，选择“保存”。
3. 展开“自动登录”，确认需要的开关：

| 开关 | 作用 | 建议 |
| --- | --- | --- |
| 统一认证自动登录 | 打开认证页时自动完成安全验证、填写并提交 | 常规使用保持开启 |
| 无感登录 | 浏览器启动后在后台先登录一次统一认证 | 默认关闭；希望之后打开认证页面更快时开启 |
| 选课系统自动登录 | 在选课登录页本地识别点击验证码并提交 | 需要时开启 |

两个网站的开关彼此独立。关闭某一项不会影响另一网站。

## 统一身份认证

访问 `https://authserver.nju.edu.cn/` 后，扩展会：

1. 检查当前页面是否仍需要登录和安全验证；
2. 在本地定位拼图缺口并完成认证页要求的验证；
3. 填入已保存的账号密码；
4. 在自动提交已开启时提交原页面表单。

定位或验证不可靠时，扩展会在有限次数后停止自动尝试并保留官方滑块。此时请人工完成，不要连续刷新页面。

### 无感登录

开启后，扩展会在每个浏览器会话中最多尝试一次后台认证。它不会打开标签页，也不会读取 Cookie 值。以下情况会跳过或取消：

- 未保存完整账号密码；
- 统一认证自动提交已关闭；
- 本次浏览器会话已经尝试过；
- 用户主动打开认证页或退出登录；
- 请求失败或超过 30 秒。

该功能不是定时保活，不能保证后续网站一定无需再次验证。

## 选课系统登录

访问 `https://xk.nju.edu.cn/` 登录页后，扩展会匹配底部目标字与上方四个候选字。只有页面尺寸、背景和置信度均满足保护条件时才会自动点击。

- 三目标验证码会换图，不会强行补点第四个字。
- 低置信度、背景变化或页面结构异常时会换图或转人工。
- “识别并标点”只显示识别位置，不会点击、填写或提交，适合人工检查。

## 课程监控

首次自动登录只负责完成选课系统认证，并停留在学校的轮次预备页；扩展不会在没有监控任务时替你进入某个轮次。请确认页面显示的批次后选择“开始选课”。只有已有任务因登录失效而暂停时，扩展才会自动衔接当前轮次入口并在课程页验证后恢复。

1. 登录选课系统并进入课程列表。
2. 优先在需要的教学班旁点击“加入监控”。扩展会保存该班的批次、类别和教学班 ID，Popup 中会显示“精确教学班”。
3. 如果暂时不能确定教学班，也可以打开扩展的“选课监控”，每行填写一个课程关键词，例如：

   ```text
   仙林游泳初级
   仙林足球初级
   ```

4. 有两个以上目标时，可以在“课程组与优先级”中调整策略：把可互相替代的目标移入同一组，设置该组的“要求数量”，再用优先级决定先尝试哪一个。数值越高越优先。
5. 选择刷新间隔。建议 5 秒或更长，并遵守学校系统规则。
6. 选择“开始监控”。日志会显示匹配、满员、组完成、已验证成功或异常状态。
7. 可以随时选择“停止监控”；全部课程组完成后也会自动停止。

实际选课页右下角默认显示可折叠的“课程雷达”，课程行内也会出现“加入监控”按钮。折叠状态可查看任务是否运行、当前轮次和下次检查时间；展开后可查看课程组进度、接口或 DOM 查询通道，以及每个目标的满员监控、提交、验证、重试和最终结果。仅配置但尚未启动的教学班显示“待启动”，明确表示当前没有运行监控。点击雷达标题栏的“×”会整体隐藏插件在课程列表中加入的雷达、行内按钮和布局增强；如需重新开启或长期关闭，请在 Popup 的“选课页增强控件”中调整。隐藏这些元素不会停止已经运行的课程监控，也不会删除任务配置。

接口查询保持串行，避免暴力并发。默认一轮可覆盖最多 12 个目标，因此常见的 5 门任务首轮都会检查；只有目标超过安全上限时才会显示“分批待查”。抢到课程并完成二次验证后，扩展会自动关闭本次操作产生的学校结果提示框，再继续处理其他目标；登录和验证码提示不会被自动关闭。

如果某个教学班返回“课程冲突”，扩展会关闭结果框并记住这个具体教学班，本次任务后续轮次不再重复提交它；同一目标还有其他教学班时会继续尝试或等待余量。只有所有候选教学班都冲突时，该目标才显示“需处理”。如果你之后主动调整了已选课表，希望重新尝试原冲突班，请停止并重新开始任务，以清空本次运行的冲突候选记录。

“加入监控”使用教学班 ID 精确匹配，适合已经选定教师、时间或班号的目标。关键词入口继续使用模糊匹配；避免只填写过短或可能同时命中多门课程的文本。精确教学班可在任务未运行时从 Popup 移除。

每个新目标默认单独成组，保持旧版“所有目标都需要抢到”的行为。需要保底时，例如羽毛球 A、羽毛球 B 和网球只需其中一门，可以把三者放入同一组并把要求数量设为 1。引擎按优先级从高到低尝试，组达标后停止同组其他目标；已经选上的保底课程不会被自动退掉换高优先级课程。

任务配置会保存在浏览器本地，旧版课程名称配置会自动迁移为关键词目标。运行状态保存在当前浏览器会话中；同一选课标签页刷新或内容脚本重新加载后会自动恢复，并先重新验证已经选上的教学班。如果刷新发生在提交附近，会先等待并验证结果，不会立即重复提交。主动停止、全部完成或浏览器会话结束后不会自动恢复运行。

遇到临时网络错误或服务端异常时，面板会显示“部分退避”，仅暂停受影响目标并逐步延长重试时间；其他目标继续监控。触发站点限流时会显示“退避中”和恢复倒计时，整个任务在倒计时结束前不再提交。该状态会随页面刷新恢复，无需手动缩短轮询间隔或反复重启任务。

如果选课登录状态失效，任务会先保存并显示“恢复登录”，随后在同一标签页打开选课系统登录页。点击验证码自动登录仍遵守原有置信门槛；不能安全自动完成时可直接人工登录。登录完成后，扩展会在轮次预备页调用网站自己的当前轮次入口，再到实际选课页核对已选状态和未确认提交后继续监控。若轮次入口不可用、页面结构异常或自动进入后仍停在预备页，会停止重复点击并请你手动选择“开始选课”。十分钟内连续三次恢复仍失效时会停止自动跳转并提示人工处理；恢复期间仍可在 Popup 选择“停止监控”。

## 暂停、更新和卸载

- 临时暂停：在扩展面板中关闭对应自动登录开关，或停止课程监控。
- 手动更新：替换解压目录内容后，在 `chrome://extensions` 或 `edge://extensions` 选择“重新加载”。
- 卸载：在浏览器扩展管理页删除 NJU Login Pro。卸载会移除该浏览器配置文件中的扩展本地数据。

账号和密码保存在浏览器扩展本地存储中，扩展不额外加密。完整边界见[隐私政策](../PRIVACY.md)。

遇到问题时继续阅读[问题排查指南](troubleshooting.md)。
