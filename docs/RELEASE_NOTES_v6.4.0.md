# NJU Login Pro v6.4.0

这是一个课程监控操作与悬浮面板可靠性更新。

## 新功能

- Popup 的课程目标区域新增“清空全部”，停止监控后连续确认两次即可一次清空全部关键词、精确教学班和课程组。
- 课程雷达的更多菜单也新增“清空全部监控目标”。如果正在监控或等待重新登录，会先停止当前任务，再执行清空。
- 课程雷达在拖动、调整尺寸、重新显示或浏览器窗口变化后，会自动保持在屏幕可见范围内。

## 稳定性修复

- 清空保存失败时不再假装成功；原目标仍保留，并可直接重试。
- 修复移除最后一个目标或清空全部后，旧兼容配置可能让目标重新出现的问题。
- 保留旧版配置的自动迁移，升级不会因为旧配置尚无课程组而丢失目标。
- 在一个页面增删目标后，已经打开的 Popup 会立即刷新课程标签。
- 修复课程雷达更多菜单危险操作分隔线和禁用态样式回退。

## 安装

- 从 GitHub Release 下载 `NJU-Login-Pro-v6.4.0.zip`。
- 解压后在浏览器扩展管理页加载该文件夹，或将同一 ZIP 提交到扩展商店。
- 不要下载 GitHub 自动生成的 `Source code` 压缩包。

本版本不新增浏览器权限，也不会修改已有课程监控目标；只有用户明确确认“清空全部”时才会删除目标配置。
