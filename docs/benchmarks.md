# 基准与运行结果

本页只汇总 README 可以引用的当前指标。详细实验、命令和样本划分保留在对应技术文档中。

## 如何理解这些数字

- 回归集用于发现版本退化，不等同于未来验证码成功率。
- 参与过开发、阈值选择或历史检查的样本不属于完全未知数据。
- 真实站点页面、服务端时序和验证码样式可能随时变化。
- 自动流程还受页面保护条件、网络和登录状态影响，不能只用模型准确率推导完整登录成功率。

## 统一身份认证拼图滑块

v6.0.0 发布前的匿名在线挑战校准为 `15/15`，平均约 `1.86s`、p95 约 `1.97s`。该检查不填写账号、不提交完整账号登录，并受当时认证站页面与服务端行为约束。

拼图流程最多尝试有限张新挑战；无法可靠验证时保留官方滑块供人工处理。

## 旧版四位图形验证码

旧版认证页面的本地 CNN/Tesseract 历史独立验证为 `146/150`，约 `97.3%`；两批未训练样本合计 `264/270`，约 `97.8%`。

这些结果仅适用于旧版四位字母数字验证码，不能代表当前拼图滑块。

## 选课中文点击验证码

历史 `round-001..020` 的浏览器 Worker 回放为 `587/600`，约 `97.83%`；平均约 `95.2ms`，p95 约 `105.7ms`。运行时使用固定背景保护和 `margin >= 0.40` 的门槛，低于门槛时换图或转人工。

这 600 张样本参与过开发或历史检查，因此是回归指标，不是未知验证码承诺。完整样本口径、复现命令和包体说明见[点击验证码运行时结果](CLICK_CAPTCHA_RUNTIME_RESULTS.md)。

## 更新规则

更新本页数字时必须同时记录：

1. 扩展或模型版本；
2. 数据集范围以及是否参与过开发；
3. 判定标准和保护门槛；
4. 运行环境；
5. 可复现命令或详细文档链接。

不得只更新 README 徽章或宣传文字而不保留评测口径。
