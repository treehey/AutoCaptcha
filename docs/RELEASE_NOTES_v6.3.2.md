# NJU Login Pro v6.3.2

这是一个课程监控交互修复版本。

## 修复内容

- 修复课程页面“移除监控”按钮点击文字时只有动画、没有执行移除的问题。
- 监控状态刷新时不再反复替换按钮文字节点，避免一次点击在按下和释放之间失效。
- 点击文字和按钮周围区域现在都会进入同一套移除确认流程。

## 安装

- 从 GitHub Release 下载 `NJU-Login-Pro-v6.3.2.zip`。
- 解压后在浏览器扩展管理页加载该文件夹，或将压缩包提交到扩展商店。
- 不要下载 GitHub 自动生成的 `Source code` 压缩包。

本版本不会改变已有监控目标、课程查询节奏或登录恢复策略。
